# Quick glossary

| Term | Simple meaning |
| --- | --- |
| AI agent | Software that uses AI to choose and carry out steps toward a task. |
| Authentication | Checking who is signing in. |
| Authorization | Deciding what a signed-in user or tool may do. |
| Buffer overflow | Writing more data into a buffer than it can hold. |
| Cold chain | Storage and transport that keep products within safe temperatures. |
| Credential | Login information, such as a username and password. |
| CVE | Common Vulnerabilities and Exposures: an identifier for a publicly disclosed vulnerability. |
| CVSS | Common Vulnerability Scoring System: a way to describe vulnerability severity. It is not a count of victims. |
| Exploit | A way to take advantage of a security weakness. |
| Internet-exposed | Reachable from the public internet. Exposure alone does not prove compromise. |
| MITRE ATT&CK | A knowledge base of behaviors attackers use. A tactic is a goal, and a technique is a way to pursue it. |
| OAuth | A framework that lets a service grant an outside application limited access. |
| Operational technology (OT) | Systems that monitor or control physical equipment. |
| Patch | An update that fixes a software problem. |
| Remote code execution (RCE) | Making another computer run code through a network connection. |
| Scope | A permission limit describing what access an application is granted. |
| Threat intelligence | Information about threats that helps people make security decisions. |

References: [MITRE ATT&CK](https://attack.mitre.org/),
[OAuth specification](https://www.rfc-editor.org/rfc/rfc6749),
[CVE program](https://www.cve.org/),
[CVSS](https://www.first.org/cvss/).
